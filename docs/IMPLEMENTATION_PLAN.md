# Plan realizacji prototypu

## Etap 1 - fundament

- przygotowanie modelu domenowego i danych demonstracyjnych,
- zdefiniowanie scenariusza prezentacji,
- utworzenie wspólnego stanu symulacji oraz możliwości resetu,
- przygotowanie responsywnej powłoki aplikacji.

## Etap 2 - kluczowe przepływy

- kalendarz i wykrywanie konfliktu zasobów,
- plan dnia i zatwierdzanie konkretnego przydziału,
- karta klienta, terapia, regularność i pakiety,
- finalizacja wizyty i rozliczenie mieszane,
- CRM, follow-up i automatyzacje.

## Etap 3 - prezentacja

- tryb prowadzonego demo krok po kroku,
- widok mobilny pracownika,
- realistyczne komunikaty, statusy i dane,
- dopracowanie dostępności, klawiatury i widoków mobilnych.

## Etap 4 - kontrola jakości

- sprawdzenie wszystkich przejść scenariusza,
- sprawdzenie kompilacji produkcyjnej,
- przygotowanie instrukcji uruchomienia i krótkiego scenariusza rozmowy z klientem.

## Plan dalszego rozwoju po akceptacji

1. Warsztat i zatwierdzenie reguł biznesowych.
2. Zamrożenie kontraktów API oraz modelu domenowego.
3. Backend, baza, role i słowniki zasobów.
4. Podłączenie istniejącego interfejsu do API.
5. Testy scenariuszy na realnych danych salonu.
6. Rozbudowa automatyzacji, raportów i migracji.
